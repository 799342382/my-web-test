## 项目简介

**AI · 工具箱** 是一个面向 AI 学习、工具导航、团队招募与资源分发的多功能前端工作台。

本项目（`live-gifts`）为早期移动端版本，目前已全面升级为 **「智汇工作台」**：页面更专业、适配 PC/平板/手机多端、新增全局搜索与更完整的账号/课程/招聘/下载模块。

---

## 主要功能

- 双层级工具与学习导航（点击卡片跳转外部工具页）
- 精品线下课程展示与报名咨询
- 团队招聘（剪辑操盘手 / 电话销售）与在线投递
- 网页 / 安卓 APP / Windows 安装包下载入口
- 本机账号保存与数据清理
- 留言 / 反馈 / 合作咨询
- PWA 支持，可添加到手机主屏幕
